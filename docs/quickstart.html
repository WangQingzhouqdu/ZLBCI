快速开始

从资料核对、软件演示到 BLE 台架采集，完成一次可检查的数据记录。

智链脑机工坊   /   资料整理 2026-10-31

准备板卡与资料

  1. 核对板卡型号、硬件版本、附件和固件版本，准备对应版本的接线图与供电说明。
  2. 准备支持 BLE 的电脑及匹配的上位机；先确认蓝牙适配器和操作系统权限。
  3. 首次在无人体连接的台架环境调试；使用内部 TEST 模式或参数合适的信号源。
  4. 断电检查电源和输入连接，按已确认的 USB 或电池方案供电。

该开发板面向教学与研发。现有材料不足以确认人体连接所需的保护与隔离；首次调试不连接人体电极。供电和接线须以实际硬件版本说明为准。

先运行软件演示

在 Python 环境中安装源码声明的依赖，然后启动模拟模式。演示模式无需板卡，用于熟悉界面和文件操作。

python -m pip install PyQt6 pyqtgraph numpy scipy bleak
python eeg_host.py --demo

模拟数据不来自采集板，不能用于验证硬件精度、通道接线或无线链路。安装依赖的具体版本未在原始 Python 文件中固定，正式交付应记录实际通过验证的环境。

连接并检查设备状态

  1. 启动真实设备模式：执行 python eeg_host.py。
  2. 扫描并选择广播名为 ESP32S3-EEG 的目标板卡；多台设备时核对设备地址。
  3. 连接后查看固件版本、采样率、增益、模式、MTU 和每包样本数。
  4. 从 250 SPS、×24 开始，以 MODE:TEST 检查采集与传输链路。
  5. 启动采集，观察 CH1–CH8 的数据更新及丢失样本、校验失败统计。

连接流程与命令格式见 通信协议；界面和记录说明见 Python 上位机。

完成一次短时记录

  1. 选择 CSV 文件路径和保存模式，初次建议保存“原始 + 滤波”。
  2. 记录一段短数据后停止记录，再停止采集。
  3. 用文本编辑器或分析程序检查文件头、time_s、sample_index 和 8 路通道列。
  4. 核对样本序号是否连续、时间间隔是否与采样率相符，并保留当时的增益与滤波参数。
  5. 关闭电源后再修改电源、模拟输入或电极连接。

内部 TEST 信号可验证部分采集链路，但不能证明电极连接器、输入保护和整个外部模拟通路均已通过测试。完成内部测试后，再按正式接线说明进行外部信号验证。

遇到问题时

现象排查方向
找不到设备板卡上电、广播状态、蓝牙权限；确认未被另一台设备占用
已连接但无波形采集是否启动、通道是否显示、当前输入模式、数据计数是否增长
校验失败或持续丢样协商 MTU、采样率、蓝牙环境、设备距离、主机后台负载
通道全零或饱和输入模式、参考/偏置连接、允许输入范围和 PGA 增益
CSV 没有写入保存路径权限、记录按钮状态、记录线程错误提示

更多排查步骤见 常见问题。
