iOS 上位机

面向 iPhone 与 iPad 的八通道 BLE 采集客户端源码，包含实时波形、参数控制和 CSV 导出。

智链脑机工坊   /   资料整理 2026-10-31

交付形式与运行环境

iOS 客户端使用 React Native / Expo，界面为中文，支持 iPhone 与 iPad。资料提供的是可构建源码，当前没有可直接安装的已签名 IPA。

运行方式用途与能力
独立 iOS App需要 Mac、Xcode 与签名配置；用于真实 BLE 设备连接、波形及本机 CSV 记录
浏览器预览用于模拟设备与界面体验；不支持真实板卡 BLE 连接
Expo Go不包含本项目所需的原生蓝牙模块，不能替代独立 App 进行真实采集

项目 package.json 声明版本 1.0.0，使用 Expo ~57.0.25、React Native 0.86.3，Node.js 引擎要求为 >=22.13.0。这些是当前资料的依赖配置，构建应使用项目锁文件。

在 Mac 上构建并安装

  1. 将 iOS 源码复制到 Mac。不要复制 Windows 下的 node_modules，在 Mac 上重新安装依赖。
  2. 准备 Node.js、Xcode 与 iOS 工具链，首次打开 Xcode 完成组件安装并选择 Command Line Tools。随附脚本提示使用 Node.js 24 LTS、Xcode 26.4 或兼容的更新版本。
  3. 用数据线连接并信任 iPhone，按系统提示启用开发者模式，在 Xcode 中配置自己的 Apple 开发账号。
  4. 在工程目录执行下方脚本，按提示选择设备。
bash build-ios-on-mac.command

脚本依次执行 npm ci、类型检查、测试，并运行：

npx expo run:ios --device --configuration Release

如遇 Team、签名或 Bundle Identifier 问题，可以先生成原生工程：

npx expo prebuild --platform ios
open ios/*.xcworkspace

在 Xcode 的 Signing & Capabilities 中选择自己的 Team 与有效签名配置。需要更改应用标识时，先修改 app.json 中的 ios.bundleIdentifier，再重新生成原生工程。Release 构建将 JavaScript 包含在应用中，安装完成后无需 Metro 服务。

真机连接与采集

  1. 给采集板上电，断开电脑或其他手机与该板卡的连接。
  2. 在设备 → 扫描蓝牙设备允许蓝牙访问，选择设备连接。扫描不到时可以关闭“只显示 EEG 设备”。
  3. 先使用默认的 250 SPS、24 倍增益验证链路。连接后，客户端会发送配置；成功写入命令不等于已经收到采样数据。
  4. 进入波形 → 开始采集，收到有效数据后才显示正在采集。
  5. 在参数页修改设置并应用时，当前采集会暂停并保存记录；完成后需重新开始采集。
  6. 进入记录选择记录内容，开始记录，结束后保存并导出 CSV。

当前实现采用前台采集：进入后台会主动停止采集并结束记录，回到前台后手动启动。首包等待阈值为 5 秒，持续采集中无有效数据阈值为 2 秒。请勿将它视为已经支持锁屏或后台连续采集。

参数与显示功能

项目功能
波形8 通道、µV 单位、通道开关、1–20 秒时间窗、自动或固定幅度
信号选择原始 / 滤波切换
采样率设置250、500、1000、2000、4000 SPS
增益与模式1 / 2 / 4 / 6 / 8 / 12 / 24 倍；NORMAL / SHORT / TEST / MVDD / TEMP
参考与检测SRB1、BIAS、导联脱落检测
滤波Butterworth SOS 流式处理，默认 0.5–45 Hz 带通，50 / 60 Hz 谐波陷波
数据校验CRC8、24 位有符号解码、样本序号回绕、丢样与导联状态

采样率设置范围与真实持续吞吐不同。iOS 的 MTU 由系统协商；完整八通道单样本数据通知至少为 39 字节，含 ATT 开销至少需要 MTU 42；MTU 23 无法容纳该帧。实际高采样率能力需以板卡、iPhone 和无线环境联调为准。

文件保存与 CSV 格式

可记录原始、滤波或两者。独立 App 将文件增量写入 Documents/EEG，可使用系统分享导出，也可在 iPhone“文件 → 我的 iPhone → 脑电采集 → EEG”访问。卸载前请导出需要保留的数据。

字段含义
# 注释创建时间、设备、真实 / 模拟标记、实际采样率与增益、滤波及请求的硬件设置
time_s从首个记录样本起算的相对秒数；不是 Python 版本的 epoch 秒
sample_index设备无符号 32 位序号，保留自然回绕
raw_ch1…raw_ch8原始通道值，µV
filt_ch1…filt_ch8滤波通道值，µV

CSV 保留收到的有效样本，绘图降采样不减少记录。缺样保留时间间隙，波形断线；重复或乱序包不重复写入。暂停、断开、设备重启、实际采样率 / 增益变化或滤波重设会结束旧文件。

浏览器预览中的 CSV 暂存在内存，刷新前应导出。浏览器存储行为与 iOS 独立 App 不同。

预览与开发检查

Windows 上可运行源码中的 01-Preview-Demo.cmd 并进入“体验演示”。模拟信号用来检查界面、滤波与 CSV 流程；MVDD / TEMP 演示仍是合成波形。

在依赖安装完成后，项目提供以下开发检查命令：

npm ci
npm run typecheck
npm run lint
npm test
npm run doctor
npm run export:ios

export:ios 生成 JavaScript / Hermes 与资源，不能生成可安装 IPA，也不能代替 Xcode 编译或硬件测试。BLE UUID 与命令结构见通信协议。

验证范围与待联调项目

随附 README 明确说明：交付环境为 Windows，未运行 Xcode；iPhone 安装包、CoreBluetooth 真机通信及 iOS 文件接口尚未实机验证。网页演示与源码检查说明软件具备相应实现，不能据此承诺 iPhone 真机链路已通过测试。

联调时先检查 250 SPS 下的连接、指令响应、有效数据与 CSV 导出，再验证目标采样率、长时间稳定性和不同手机型号。客户端负责采集、显示与导出，不提供疾病判断。
