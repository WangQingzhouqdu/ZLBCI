Android 上位机

在 Android 手机上通过 BLE 连接八通道采集板，查看波形、调整参数并导出 CSV。

智链脑机工坊   /   资料整理 2026-10-31

版本与安装

资料中提供 脑电采集 v1.0.0，使用 Kotlin 开发，适用于 Android 8.0 及以上。真实采集需要手机具备 BLE 功能；应用运行不依赖 Python 或电脑。

  1. 在下载中心取得 Android APK，复制到手机。
  2. 用文件管理器打开 APK，按系统提示允许该文件管理器安装应用，并完成安装。
  3. 打开“脑电采集”。首次使用可以先开启模拟设备，熟悉界面后再连接板卡。

当前资料包含 APK 与 Android 源码。源代码中的版本号为 1.0.0，minSdk = 26，应用标识为 com.eeg.mobile。

连接与开始采集

  1. 给采集板上电，断开电脑端或其他手机与该板卡的 BLE 连接。
  2. 进入设备 → 扫描蓝牙设备。按系统提示允许“附近设备”；Android 11 及以下还需定位权限并开启系统定位。
  3. 在扫描结果中点击采集板。默认筛选名称包含 EEG 或广播指定服务 UUID 的设备；未找到时可以关闭“只显示 EEG 设备”。
  4. 进入参数，先使用 250 SPS、24 倍增益，设置输入模式、SRB1、BIAS 与导联检测，然后应用采集参数。
  5. 进入波形 → 开始采集。确认有效数据到达、通道波形更新，再开始记录。

应用参数会暂停采集并结束当前记录。BLE 连接由前台服务维护；实际后台表现受手机系统限制。当前代码在启动后等待首个有效包的阈值为 5 秒，持续采集中无有效包的阈值为 1.5 秒，超时会暂停并保存记录。

连接成功、指令写入成功与持续收到有效脑电数据是不同状态，联调时应同时观察样本率、丢样和波形。

波形、参数与滤波

功能当前客户端行为
通道与单位8 通道，单位 µV；点击通道编号可显示或隐藏通道
波形显示时间窗、幅度范围、原始 / 滤波切换；导联检测开启时异常通道显示 !

建议先在 250 SPS 下验证链路，再按固件说明逐步提高采样率。修改采集或滤波配置会结束旧记录，避免把不同配置混入同一文件。

记录与导出 CSV

  1. 开始采集后，进入记录。
  2. 选择“原始 + 滤波”“仅原始”或“仅滤波”，点击“开始记录”。
  3. 完成后点击“停止记录并保存”。
  4. 点击已保存文件，通过系统文件选择器导出到“下载”等位置。
字段含义
# 注释设备、创建时间、真实 / 模拟标记、采样率、增益、参考与滤波设置
time_s本次记录的相对秒数，与 Python 上位机的绝对时间列不同
sample_index设备无符号 32 位样本序号
raw_ch1…raw_ch8各通道原始值，单位 µV，按记录模式选入
filt_ch1…filt_ch8各通道滤波值，单位 µV，按记录模式选入

绘图降采样只影响屏幕显示，CSV 保存收到的全部有效样本。缺样通过序号与时间间隙体现，不插值补造测量值。文件默认保存在应用私有存储中；需要保留的记录应在卸载应用前导出。

无硬件演示

在设备 → 开启模拟设备 → 开始采集启动演示。界面显示“模拟数据”，生成八通道合成波形，可操作滤波、参数与 CSV 记录。模拟模式不需要蓝牙权限。

模拟信号用于验证软件操作流程。MVDD / TEMP 模式下的演示仍是合成波形，不代表真实电源电压或温度。离开应用较长时间后，模拟采集会暂停并保存记录。

源码构建与协议

使用 Android Studio 打开 Android 工程，或在已配置 Android 工具链的终端中运行：

.\gradlew.bat assembleDebug testDebugUnitTest lintDebug

调试包用于本地开发。生成发行包时需配置自己的发行签名，再执行 assembleRelease；覆盖升级需要保持相同包名与签名并提高 versionCode。公开源码包不应包含开发者签名材料。

工程配置记录：AGP 9.4.1、Gradle 9.6.0、compile / target SDK 36、min SDK 26；Java 源代码兼容级别为 21。请以随工程提供的 Gradle 配置与包装器为准。

BLE 服务 UUID 为 6e400001-b5a3-f393-e0a9-e50e24dcca9e，RX / TX / STATUS 分别使用 6e400002、6e400003、6e400004 同后缀。RX 接收带响应写入的换行结尾文本命令，TX 通知二进制数据，STATUS 通知可选 JSON 状态。完整命令和帧结构见通信协议。

验证范围

随附 README 记录了单元测试、Android Lint、签名检查，以及 Android 模拟器安装运行的验证结果。本网站整理过程未重新执行这些应用测试。

原资料明确说明：未在交付测试环境连接真实 ESP32-S3 + ADS1299 采集板。因此 BLE 真机连接、指令应答、电极信号与持续吞吐仍需结合实际板卡和手机验证。模拟波形或模拟器运行不能替代硬件联调。
