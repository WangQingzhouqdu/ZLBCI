固件与硬件接口

Arduino 固件文件、GPIO 映射、任务流程与版本适配要点。

智链脑机工坊   /   资料整理 2026-10-31

源码与开发环境

主文件为 ESP32S3_ADS1299_EEG.ino，声明的固件版本为 1.0.0。文件头以 Arduino IDE / arduino-cli、Espressif esp32 开发板包 2.0.x 或 3.x、ESP32S3 Dev Module 为开发目标。

这些是源码声明的环境，原资料未附与本页对应的完整编译矩阵。构建前应固定实际开发板包版本、模组类型、Flash/PSRAM 与 USB 设置，并以目标板编译和台架运行结果确认兼容性。

  • 核心依赖：Arduino、SPI、BLEDevice、BLEServer、BLEUtils；按头文件是否存在使用 BLE2902。
  • 串口日志波特率：115200。
  • 采集 SPI：FSPI，4 MHz，MSB first，SPI_MODE1。
  • 默认广播名称和版本号可分别通过 BLE_DEVICE_NAME 与 FW_VERSION 修改。

参考与输入模式

默认配置将 MISC1.SRB1 置位，使用 SRB1 作为通道公共参考，通道 SRB2 关闭。BIAS_SENSP 随偏置开关设为 0xFF 或 0x00；负端不参与该反馈配置。

模式源码对应输入适用调试目的
NORMAL正常输入外部已确认的测试信号
SHORT输入短接模式观察内部短接条件下的数据
TEST内部测试信号检查采集、打包与软件链路
MVDD供电测量输入芯片内部调试
TEMP温度传感输入芯片内部调试

这些模式使用同一组通道配置，当前命令没有提供逐通道独立增益或独立模式。MVDD 与 TEMP 输出若要解释为电压或温度，还须按芯片对应模式定义换算，不能直接当作脑电幅值。

固件工作流程

  1. 初始化 GPIO、SPI 和 ADS1299，读取 ID，写入默认工作寄存器。
  2. 采集任务固定于 core 1，DRDY 中断递增计数并唤醒任务。
  3. 每次读取 27 字节帧，将 8 路原始样本与绝对序号写入环形缓冲。
  4. BLE 发送任务运行于 core 0，按 MTU 与连续样本数量组织数据包。
  5. BLE 写入回调只将命令入队；loop() 执行参数修改并定期发送状态。

断开 BLE 时，固件停止正在进行的采集并重新广播。重新连接后由上位机恢复配置并再次启动采集。

构建与联调检查

  1. 将源码放入与草图同名的 Arduino 文件夹，选择实际 ESP32-S3 目标配置。
  2. 核对 PIN_*、供电电平、主控模组与 ADS1299 硬件连接。
  3. 完成编译与下载后，通过串口查看 ADS1299 ID 和 BLE 广播日志。
  4. 先以 TEST、250 SPS 和 ×24 验证链路，再逐项调整配置。
  5. 记录所用开发板包、编译参数、固件校验值及台架测试结果，与上位机一起归档。

更改数据帧或命令时，同步更新 协议说明 和各平台解析器。文件头的旧命令注释仅列到 4000 SPS，但实际处理函数包含 8000 / 16000；对接时以代码和验证结果为准。
