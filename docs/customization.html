定制与交付验收

明确板卡、软件与资料范围，以可复现的测试完成项目交付。

智链脑机工坊   /   资料整理 2026-10-31

先描述需要实现的结果

板卡与 Android、iOS、Windows 上位机可按项目需求评估。先提交应用场景、目标平台、数量、核心功能和期望交付物，再确定接口和验收方式。

需求方向需要说明的内容
采集与数据通道与输入、采样配置、记录时长、数据格式、时间戳与同步
硬件与结构尺寸、安装孔、连接器、电源、电池、配件和外壳
上位机目标系统与设备、连接方式、曲线、滤波、保存、回放与导出
资料与授权固件、上位机源码、原理图、PCB、BOM、SDK；分别确认使用权限
测试与支持验收环境、阈值、交付日期、问题反馈和支持范围

交付清单建议

编号交付项应记录的信息
H01板卡与配件硬件版本、数量、附件型号、外观与电气检查项目
F01固件文件格式、版本、硬件兼容范围、烧录与恢复步骤
S01上位机平台、系统版本、功能、安装包与源码范围
D01文档与样例接线、协议、文件格式、示例输入输出和环境版本
A01开发支持渠道、期限、次数或工时、问题反馈方式

每项写明数量、文件格式和可验收行为。源码交付不自动包含商用、再分发或生产授权；第三方组件的许可也应一并记录。

建议里程碑

  1. 需求确认：冻结目标硬件、平台、功能、资料与授权范围。
  2. 样机联调：使用模拟信号验证接口、数据帧和连接流程。
  3. 功能验收：按约定环境与阈值测试，并保存原始数据和缺陷记录。
  4. 正式交付：板卡、固件、上位机、文档版本相互匹配。
  5. 后续变更：记录变化、受影响模块、进度和新的验收条件。

可复现的验收项目

测试项目方法与记录
8 通道映射逐通道注入已知测试信号，核对端口、编号和极性
配置一致性设置采样率、增益和模式，检查回读与数据输出
数据率与连续性使用独立计时基准，统计应收/实收样本、序号缺口和校验失败
记录与导出核对列名、单位、时间、样本数及文件重新读取
平台兼容在约定设备和系统上测试安装、连接、采集、保存和恢复
整板性能按约定输入、带宽、增益和时长记录噪声、幅值误差等指标

每项结论使用“通过 / 附条件通过 / 未通过 / 未测试”，并记录硬件、固件、软件、输入、供电和测试设备。空白模板不代表已经通过测试，静态截图也不能替代连续采集记录。
